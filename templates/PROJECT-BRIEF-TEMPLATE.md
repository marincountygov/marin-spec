# Project brief: (project name)

Write in active voice and plain language.

## Project

What are we building?

## Problem

What are we trying to accomplish? Write the underlying goal, not the solution.

Weak: "We want to add a search box."

Strong: "Residents cannot find the permit status they need, so they call staff. We want them to find it themselves."

## Why this matters

Why does this deserve time and resources? Use evidence: survey results, usage data, or a policy or leadership driver. Mark each point Confirmed or Inferred.

## Users

Who needs it?

## Experience

What should users be able to do?

## Scope

What is included?

## Not included

What is outside the project?

## Key decisions

What has already been decided?

## Deadlines

Are any dates driving this project? Leave this out if there are none.

## Key risks and mitigation

What could go wrong, and what would reduce the risk? Leave this out if there are none.

## Open questions

What still needs an answer?

## Success

How will we know this worked?
